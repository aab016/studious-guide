🎮 Demo Disponibili
1. Template WebXR
Punto di partenza essenziale per sviluppare esperienze VR. Include navigazione della camera tramite joystick e struttura base pronta all'estensione.
→ Accedi al Template
2. IWSDK Locomotion
Implementazione avanzata di sistemi di movimento e locomotion per esperienze immersive. Perfetto per capire come far muovere l'utente nello spazio virtuale.
→ Prova la Locomotion
📖 Per approfondire: leggi il README del progetto IWSDK
3. Immersive Web Emulation Runtime (IWER)
Sperimentazione con il runtime di emulazione WebXR. Inclusi esempi pratici e approfondimenti sugli standard web per la realtà virtuale.
→ Esplora IWER
📚 Basato su: Meta Quest - IWER
4. Template con Modelli 3D (Sketchfab)
Integrazione di modelli 3D professionali da Sketchfab dentro esperienze VR WebXR. Vedi come portare asset di qualità nelle tue scene immersive.
→ Vedi il Template Sketchfab
5. Multiplayer VR Room
Esperienza collaborativa in realtà virtuale. Multiple utenti possono condividere lo stesso spazio virtuale in tempo reale.
→ Accedi alla Room
⚙️ Prerequisito: esegui npm run wss:server prima di accedere
6. Classroom Presence
Prototipo di aula virtuale dove studenti e insegnanti possono interagire in VR. Sperimenta con sistemi di presence e avatar sociali.
→ Entra in Aula
🔐 Richiede: login con account Oculus/Meta
